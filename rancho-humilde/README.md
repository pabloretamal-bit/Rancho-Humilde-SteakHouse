# Rancho Humilde — sitio estático

Sitio conceptual ficticio para un steakhouse Wagyu premium en Ancud, Chiloé.

## Archivos
- `index.html`: contenido y secciones
- `styles.css`: diseño responsive
- `script.js`: carta interactiva, menú móvil y demo de reservas

## Publicar en GitHub Pages
1. Descomprime este archivo.
2. En tu repositorio `rancho-humilde`, entra en **Add file → Upload files**.
3. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio, reemplazando los anteriores.
4. Pulsa **Commit changes**.
5. En **Settings → Pages**, confirma `Deploy from a branch`, rama `main`, carpeta `/ (root)`.
6. Espera un par de minutos y recarga la URL publicada.

## Importante
- La carta, los precios y la agenda de shows son contenido de demostración. La programación usa fechas futuras de muestra; confirma disponibilidad de artistas, intérpretes de tributo, fechas y horarios antes de presentarlos como eventos reales.
- Las imágenes se cargan desde Unsplash y requieren conexión a internet.
- El formulario de reservas es una demo y no envía datos ni crea reservas reales.
- Para cambiar platos, edita el objeto `menuItems` en `script.js`.
